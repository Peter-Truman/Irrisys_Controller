### SYSTEM OVERVIEW

The IRRISYS Pump Guard protects irrigation pumps by monitoring up to 3 analog
sensor inputs (4-20mA) and controlling a relay output. The system monitors
pressure, temperature and flow conditions, applying configurable bypass timers
at startup and during operation, and stopping the pump when thresholds are
exceeded.

**Two-Board Architecture:**
- Main Board (PIC18F26K22 @ 32MHz) — control logic, ADC, RTC, relay, encoder
- Display Board (PIC18F14K22 @ 8MHz) — 4x20 LCD, 3x LEDs, brightness/contrast PWM
- Communication: Main → Display via serial (19200 baud, 8N1)

### RELAY & STOP CODE SYSTEM

The relay is normally energized (closed = pump can run). The controller
de-energizes (opens) the relay to stop the pump. This is fail-safe: if the
controller loses power, the relay drops and the pump stops.

**Two Relay Modes:**

| Mode | Behaviour |
|------|-----------|
| Pulse | Relay opens on threshold. Stays open while DIG_IN1 is high. When DIG_IN1 goes low (pump stopped), waits relay_pulse_time seconds then re-energizes. Ready for next run. |
| Latch | Relay opens on threshold. Stays open until momentary button is pressed. Survives power cycles. DIG_IN1 cycling cannot clear a latched fault. |

**Stop Codes** (persisted to EEPROM):

| Code | Text | Trigger |
|------|------|---------|
| 0 | (none) | Normal operation |
| 1 | End Clk | Runtime countdown expired |
| 2+ | (future) | Sensor threshold faults |

**Stop Code Clearing:**
- Button press: clears any stop code, closes relay
- DIG_IN1 going high: clears non-latched stop codes only
- Latched faults: button press is the ONLY way to clear

**Boot Sequence:**
1. Relay starts de-energized (safe)
2. Boot completes (peripherals, splash screen)
3. Check for active_stop_code in EEPROM
4. If latched fault: relay stays de-energized, blocked until button press
5. If no fault: relay energizes, ready to run

### CLOCK & RUNTIME SYSTEM

When the clock is enabled, a countdown timer runs during SYS_RUN state.

**Main Screen Line 1 (when running with clock):**
```
RUN  HH:MM:SS  HH:MM
     countdown  current time
```

**When clock disabled:** run_timer_secs counts UP (elapsed time).

**Runtime Expiry:**
- Timer reaches zero → trigger_relay_pulse(mode) based on end_runtime_mode
- Stop code 1 ("End Clk") set and saved to EEPROM
- Relay action (pulse or latch) per clock menu setting

**Timer Restart:**
- When DIG_IN1 cycles (STOP→RUN), timer reloads from configured runtime

### ADC & SENSOR INPUTS

**3 Analog Inputs (4-20mA):**
- 10-bit ADC with FVR 2.048V reference
- 4mA = ~205 counts, 20mA = ~1000 counts
- 4-sample rolling average at ~20Hz
- Engineering units: linear interpolation between scale_4ma and scale_20ma

**Sensor Types (per input):**

| Type | Display | Fields |
|------|---------|--------|
| Pressure | PPP psi | Scale 4/20mA, Hi/Lo setpoints, High/PLP/SLP bypass, relay modes |
| Temperature | ±TT C | Scale 4/20mA, Hi/Lo setpoints, High bypass, relay mode |
| Flow | FFF L/m or FLOW/NO FLOW | Analog or Digital mode, scale, low flow setpoint/bypass |

**Main Screen Lines 2-4:** Show enabled inputs with engineering values and units.
Asterisk (*) at column 19 indicates input is enabled.

### BYPASS TIMER SYSTEM

Bypass timers allow threshold conditions to exist temporarily without triggering
a stop. This handles startup transients (e.g., pressure takes time to build).

**Primary Low Pressure Bypass (PLPBP) — one-shot, startup only:**
- Loaded when RUN input goes high
- Decrements while pressure < low threshold
- If pressure reaches threshold: PLPBP cancelled (served its purpose)
- If PLPBP expires while still below threshold: pump stops (PLPBP fault)
- Cannot be reused within a single RUN cycle

**Secondary Low Pressure Bypass (SLPBP) — reusable, episode-based:**
- Ignored while PLPBP is still active
- Activates only after PLPBP has been cancelled (pressure reached threshold)
- Each pressure-drop episode reloads the timer
- Episode ends when pressure recovers above threshold
- If SLPBP expires during an episode: pump stops (SLPBP fault)
- PLPBP cannot flow into SLPBP — if pressure never reaches threshold during
  PLPBP, the pump stops immediately. No second chance.

**High Pressure Bypass (HPBP):** Episode-based (like SLPBP) for high pressure.

**Low Flow Bypass:** Episode-based for low flow conditions.

**Status:** Bypass timer logic is defined but not yet implemented in firmware.
The relay/stop code infrastructure is ready to support it.

---

### POWER FAILURE DETECTION

1. On RUN entry: power_failure_flag armed (set to 1, saved to EEPROM)
2. On normal STOP (DIG_IN1 goes low): start pwr_detect_countdown
3. Countdown expires: clear power_failure_flag (normal stop confirmed)
4. If power fails during RUN: flag remains set in EEPROM
5. On next boot: detect flag, display "PWR FAIL", button acknowledges

### EEPROM MEMORY MAP

| Address | Size | Content |
|---------|------|---------|
| 0x000 | 128 | Input 1 config (input_config_t) |
| 0x080 | 128 | Input 2 config |
| 0x100 | 128 | Input 3 config |
| 0x180 | 128 | System config (system_config_t) |
| 0x200 | 2 | Checksum |

**Per-Input Structure (128 bytes):**
- Basic: enable, sensor_type, flow_type, flow_units, display_enabled
- Signed 16-bit: scale_4ma, scale_20ma, temp_low
- Unsigned 16-bit: high_setpoint, high_bypass_time, plp_bypass_time,
  slp_bypass_time, low_flow_setpoint, low_flow_bypass
- Relay modes: relay_high_mode, relay_plp_mode, relay_slp_mode, relay_low_mode
- Padding for future expansion

**System Structure (128 bytes):**
- Clock: clock_enabled, menu_timeout, runtime_hours, runtime_minutes,
  end_runtime_mode, relay_pulse_time
- Display: contrast, brightness, power_fail_delay, power_failure_flag
- Logging: log_entries
- Runtime: active_stop_code
